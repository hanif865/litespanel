ModSecurity WAF

Admin-only. ModSecurity is a Web Application Firewall that inspects every HTTP request and blocks common attacks — SQL injection, cross-site scripting, path traversal and more — using the OWASP Core Rule Set. It filters traffic for the whole host, so switching it on affects every site.

About the rules

Blocking (On) rejects requests that match a rule with a 403. Detection Only logs matches without blocking — use it to check for false positives before enforcing. Matches are written to the nginx error log and the ModSecurity audit log; view them under Logs.
