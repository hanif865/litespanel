Web Fronting — Varnish cache

Sandwiches every hosted site behind a Varnish HTTP cache: nginx (TLS) → Varnish → nginx → PHP-FPM. Cacheable responses get served straight from RAM. Flipping this rewrites every site's nginx vhost and restarts Varnish; while it's on, new SSL certs are issued over the ACME webroot so the sandwich stays intact. The panel's own domain is never fronted, and Varnish binds to localhost only — public ports and the firewall don't change.
